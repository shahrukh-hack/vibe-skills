## 🚀 1-Command CLI Installation

Install any skill directly into your project's `.antigravity/skills/` or `.cursor/skills/` directory with 1 command:

```bash
# List all 23 available skills
npx vibe-skills list

# Install a specific skill
npx vibe-skills add taste-engine
npx vibe-skills add code-review
npx vibe-skills add browser-automation-scraper
npx vibe-skills add owasp-security-sentinel
npx vibe-skills add nextjs-app-router-guard
```

## 🛠️ How AI Agents Use Vibe Skills (Examples)

When a skill is installed into your workspace, AI coding agents (Antigravity, Cursor, Claude Code) automatically activate them based on your prompts:

### Example 1: Triggering a 4-Phase Code Review across 20+ Languages
```markdown
# Prompt to Cursor / Antigravity:
"Review my pull request against our production standards using the code-review skill."

# What the Agent Executes:
1. Phase 1: Architecture & Intent Review
2. Phase 2: Security & Vulnerability Check (SQLi, XSS, BOLA)
3. Phase 3: Language-Specific Idioms (Go error wrapping, Python typing, Rust lifetimes)
4. Phase 4: Structured Markdown Summary with Diff Suggestions
```

---

### Example 2: Running a Playwright Web Scraper
```markdown
# Prompt to Claude Code / Antigravity:
"Extract the latest product pricing from the target URL using the browser-automation-scraper skill."

# What the Agent Executes:
- Launches headless Playwright with stealth user-agent headers
- Waits for network idle and SPA DOM hydration
- Extracts clean tabular data and writes directly to SQLite / JSON
```

---

### Example 3: Auditing a Pull Request for Secret Leaks
```markdown
# Prompt to Cursor / Antigravity:
"Scan this repository for security vulnerabilities using the owasp-security-sentinel skill."

# What the Agent Executes:
- Regex scans for leaked keys (`ghp_`, `sk_live_`, AWS Secret Access Keys)
- Audits API endpoints for missing authentication middleware
- Flags unescaped `dangerouslySetInnerHTML` calls
```
