# 🎨 BrandKit: Brand Identity & Token Architecture Skill

> **Purpose**: Establish bespoke, high-end brand identity systems that give digital products distinct personality, memorability, and visual consistency.

---

## 🏛️ Brand Architecture Framework

1. **Color Palette Construction**:
   * Canvas / Background (97% Lightness or 6% Dark Navy)
   * Primary Action Blurple / Indigo
   * Secondary Supporting Tint
   * Neutral Slate / Almond Ink
   * Functional Accents (Success Emerald, Warning Amber, Destructive Crimson)
2. **Typography Pairing Matrix**:
   * Hero Display: High-character optical serif (`Fraunces` / `Playfair`) or geometric grotesque (`Space Grotesk`)
   * Body / Interface: Neutral, ultra-legible sans (`Plus Jakarta Sans` / `Inter Tight`)
   * Telemetry / Code: Crisp monospaced (`JetBrains Mono`)
3. **Design System Token Export**: Output clean CSS variables for Tailwind CSS and Figma tokens.
