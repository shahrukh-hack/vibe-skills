# 🖼️ ImageGen Frontend Web Prompting Skill

> **Purpose**: Generate high-fidelity visual UI references, design comps, and website wireframes using image generation models (ChatGPT Images, Midjourney) before handing them to coding agents for implementation.

---

## 🎯 Composition Prompt Anchors

When formulating visual prompts for web design, always include:
* **Layout Geometry**: "Clean modern 60/40 asymmetrical landing page layout, pure white card containers with 1px subtle borders"
* **Lighting & Atmosphere**: "Soft ambient natural lighting, zero neon purple glow, subtle studio paper texture"
* **Color Hierarchy**: "Stripe enterprise palette: #F6F9FC soft slate-white canvas, #0A2540 deep navy typography, vibrant #635BFF indigo accent buttons"
* **Focal Element**: "Central interactive card with animated telemetry data and minimalist vector icons"
