# 🧵 Stitch Design System Skill

> **Purpose**: Unify diverse UI components, external primitives, and micro-interactions into a single, seamless design token system with harmonious colors, typography, and density.

---

## 🎨 Semantic Token Harmonization

1. **Global CSS Variable Mapping**: Ensure all external components consume the same `--background`, `--foreground`, `--primary`, `--border`, and `--radius` tokens.
2. **Unified Border Radius**: Synchronize `--radius: 0.625rem` across all cards, modals, dropdowns, and buttons.
3. **Fluid Viewport Scaling**: Use CSS `clamp()` for responsive typography and padding across mobile, tablet, and desktop breakpoints.
