## 🚫 Forbidden AI Clichés (Zero Tolerance)

- ❌ **No Purple Gradients on Dark Theme**: Banned. Default to Stripe Enterprise Navy (`#0A2540`), Tailwind UI Slate, or crisp white cards.
- ❌ **No Pulsing Headline Pills**: Banned. Use structured mono badges (`[ 01 / ARCHITECTURE ]`) or editorial kicker lines.
- ❌ **No Gradient Keywords in Headlines**: Banned. Text must be solid, crisp, and weighted with optical kerning.
- ❌ **No Over-Nested Cards**: Never put 3+ rounded cards inside another rounded card.
- ❌ **No Untracked Large Typefaces**: Large headlines must have tighter letter-spacing (`tracking-tight` or `-0.03em`).
- ❌ **No Lazy Code Truncation**: Never output `// TODO: implement later` or truncated snippets. Always write fully functional code.

## ✅ Enforced Design Standards

1. **Emil Kowalski Physics**: All interactive micro-animations must use spring physics (`stiffness: 420`, `damping: 30`, `mass: 0.6`).
2. **Stripe & Tailwind UI Palette**: Use `#F6F9FC` background canvas, `#0A2540` navy headings, `#635BFF` blurple action buttons, and pure white elevated cards with 1px border (`#E3E8EE`).
3. **Tactile Surfaces**: Use subtle border accents, layered depth cards, and active tactile press states (`scale: 0.96`).
4. **Image-to-Code Pipeline**: When given mockups or reference frames, extract layout structures, color matrices, and typography hierarchies before generating code.
5. **Redesign Protocol**: When refactoring existing interfaces, preserve all state logic and props while upgrading layout hierarchy and token systems.
