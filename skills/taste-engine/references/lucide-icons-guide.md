# Lucide Icons & Visual Hierarchy Standards

## 1. Stroke Width Consistency
* Default stroke width: `strokeWidth={2}` or `1.75` for modern editorial feel.
* Standard sizing hierarchy:
  - Micro-adornments (inputs, badges): `w-3.5 h-3.5` (14px)
  - Standard button & navigation icons: `w-4 h-4` (16px)
  - Hero & card feature icons: `w-5 h-5` (20px) or `w-6 h-6` (24px)

## 2. Icon Wrapping & Padding
* Wrap icons in soft rounded backgrounds (`p-2 rounded-xl bg-muted text-foreground`).
