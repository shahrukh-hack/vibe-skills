# UI UX Pro Max Mathematical Design Specifications

## 1. The 8pt Spatial Grid Rule
* Micro-spacing: `4px` (`gap-1`), `8px` (`gap-2`), `12px` (`gap-3`)
* Container padding: `16px` (`p-4`), `24px` (`p-6`), `32px` (`p-8`), `48px` (`p-12`)

## 2. Modular Typographic Scale (1.250 Major Third)
* Large Display: `3rem` to `3.75rem` (`text-5xl` / `text-6xl`) with `-0.025em` tracking.
* Section Headings: `1.875rem` to `2.25rem` (`text-3xl` / `text-4xl`).
* Card Headings: `1rem` to `1.25rem` (`text-base` / `text-lg`).
* Body Text: `0.875rem` (`text-sm`) or `0.75rem` (`text-xs`) with `leading-relaxed`.

## 3. WCAG AAA Contrast Mathematics
* Minimum 4.5:1 for normal text, 7:1 for enhanced contrast.
* Always pair light backgrounds with deep navy (`#0A2540`) or slate (`#0F172A`).
