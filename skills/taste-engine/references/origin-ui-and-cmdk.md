# Origin UI & cmdk Precision Input Controls Guide

## 1. Input Fields with Adornments & Shortcuts
* Left Adornment: Semantic context icon (`Search`, `Mail`, `Lock`).
* Right Adornment: Interactive actions (Clear `✕`, Show/Hide Password `👁`, Copy `📋`).
* Keyboard shortcut indicators: `<kbd className="px-1.5 py-0.5 rounded bg-muted font-mono text-[10px]">⌘K</kbd>`.

## 2. Command Palette Menus (`cmdk`)
* Fast in-memory fuzzy search across components, actions, and settings.
* Instant keyboard traversal (`ArrowUp`, `ArrowDown`, `Enter`, `Escape`).
* Grouped action sections with visual badges.

## 3. Segmented Control Switchers
* Animated pill slider with spring layout morphing.
* Clear active/inactive contrast deltas.
