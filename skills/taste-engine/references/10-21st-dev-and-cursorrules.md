# 10. 21st.dev Registry & Awesome Cursorrules Playbook (30k+ ⭐)

> **Core Philosophy**: *Open copy-paste component architecture for AI coding agents. Calibrated system prompts that permanently ban AI slop.*

---

## 🔌 1. 21st.dev Component Integration Standard

Components must be 100% self-contained, typed, and copy-pasteable:
1. **Explicit Utility Imports**: Import `cn` from `@/lib/utils` and `SPRING_PRESETS` from `@/lib/motion-presets`.
2. **Strict TypeScript Typing**: Every component must export typed interfaces for all props.
3. **No Lazy Placeholders**: Never leave `// TODO` comments in production code.

---

## 🛡️ 2. Universal `.cursorrules` Anti-Slop Template

When an AI agent initializes a project, inject this calibrated taste guard into `.cursorrules` or `.antigravity/rules`:

```markdown
# High-Taste Design & Anti-Slop Guardrails
You are an expert design engineer crafting bespoke, human-feeling web applications.

## Strictly Banned AI Tropes:
- NO neon purple or cyan glows on dark backgrounds.
- NO pulsing pill badges above headlines ("✨ Next-Gen AI").
- NO CSS gradient text across headline keywords.
- NO linear or ease-in-out CSS transitions. Always use spring physics (stiffness: 420, damping: 30).
- NO un-tracked Inter font on everything. Pair Fraunces with Plus Jakarta Sans.

## Enforced Standards:
- Stripe Enterprise Palette: #F6F9FC canvas, #0A2540 navy headings, #635BFF blurple CTA, pure white cards with 1px border (#E3E8EE).
- Emil Kowalski button physics: scale: 0.96 on click, y: -1.5px on hover.
- Full output enforcement: write 100% complete, working code.
```
