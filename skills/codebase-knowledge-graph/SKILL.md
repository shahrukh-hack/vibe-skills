# 🧠 Codebase Knowledge Graph Skill

> **Purpose**: Map high-level module dependencies, cross-file imports, and function call hierarchies across complex multi-package repositories.

---

## 🗺️ Knowledge Mapping Protocols

1. **Import Dependency Graphing**: Trace circular dependencies and isolate decoupled utility packages.
2. **Data Flow Tracing**: Map how user inputs traverse from frontend components $\rightarrow$ API endpoints $\rightarrow$ database mutations.
3. **Dead Code Detection**: Identify unreferenced exports, unused CSS selectors, and orphaned types.
