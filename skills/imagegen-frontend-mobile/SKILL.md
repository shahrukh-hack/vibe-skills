# 📱 ImageGen Frontend Mobile Prompting Skill

> **Purpose**: Generate high-fidelity mobile UI references, iOS/Android screens, and native bottom-sheet interaction comps using image generation models before handing them to coding agents.

---

## 🎯 Mobile Composition Prompt Anchors

When formulating visual prompts for mobile interfaces, always include:
* **Frame & Safe Area**: "Clean iOS mobile app mockup, modern dynamic island status bar, bottom home indicator bar"
* **Component Anchors**: "Bottom navigation tab bar with 4 minimalist icons, central elevated CTA button, card list with smooth rounded corners (24px radius)"
* **Surface Styling**: "Soft white background, subtle glassmorphism blur on navigation bar, crisp 1px borders (#E3E8EE), zero neon glow"
* **Typography & Palette**: "Stripe enterprise palette: #F6F9FC canvas, deep navy titles, #635BFF blurple active icons, Plus Jakarta Sans typography"
