# 🌟 UI UX Pro Max — Agency-Grade Design Intelligence Skill

## 🎯 Purpose
Equips AI coding agents with the design intuition of a Principal Product Designer and Design Engineer.

## 🛠️ Core Capabilities:
1. **Responsive Viewport Fluidity**:
   - Zero content jumping across breakpoints (`sm`, `md`, `lg`, `xl`).
   - Internal button and input dimensions scale proportionally with their container.
2. **Accessible Form Controls (WCAG AAA)**:
   - Built on top of Radix UI primitives with keyboard navigation (`⌘K` command palettes, arrow key focus, tab loops).
3. **Stacked Notification Architecture**:
   - Uses Sonner micro-toasts with customizable status badges and tactile dismiss transitions.
4. **State Machine Micro-Interactions**:
   - Hover states, focus rings, disabled states, and optimistic UI loading spinners.
