# ⚡ GPT & Codex Taste Enforcement Skill

> **Purpose**: Aggressively override default LLM laziness, centering everything, and default generic styling by forcing strict creative layout structures and high-fidelity motion.

---

## 🚫 Overridden Default LLM Behaviors

1. **Overridden**: Centered hero with generic title + subtitle + 2 buttons $\rightarrow$ **Enforced**: Asymmetric 60/40 split with interactive live sandbox, kicker tag, and optical typography.
2. **Overridden**: `transition: all 0.3s ease` $\rightarrow$ **Enforced**: Physics springs (`stiffness: 420, damping: 30`) or GSAP timeline velocity.
3. **Overridden**: Un-tracked Inter font $\rightarrow$ **Enforced**: `Fraunces` (optical size 144) paired with `Plus Jakarta Sans` with tight tracking (`-0.03em`).
4. **Overridden**: Symmetrical 3-column card grid $\rightarrow$ **Enforced**: Asymmetric 3-tier enterprise bento grid.
