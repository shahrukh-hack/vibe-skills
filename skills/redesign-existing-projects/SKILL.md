# 🔄 Redesign Existing Projects Skill

> **Purpose**: Safely transform dated, clumsy, or generic AI-slop components into high-taste, bespoke interfaces without breaking existing application functionality.

---

## 🛡️ The 4 Golden Rules of Non-Destructive Redesign

1. **Zero Logic Regressions**: Preserve all existing component props, callbacks, `useState`, `useEffect`, React Query queries, and backend API contracts.
2. **Eliminate Generic AI Tropes**:
   * Replace neon purple glows with crisp 1px subtle borders (`#E3E8EE`).
   * Replace pulsing badge pills with structured mono kickers (`[ 01 / LIVE ]`).
   * Replace linear CSS transitions with Emil Kowalski 420Hz spring physics.
3. **Upgrade Typographic Foundations**:
   * Replace generic un-tracked Inter with `Plus Jakarta Sans` for body and `Fraunces` / `Space Grotesk` for headlines.
   * Tighten letter spacing on large display titles (`tracking-tight`).
4. **Enforce 8pt Spatial Balance**:
   * Standardize all arbitrary padding (`p-[13px]`) into strict 8pt grid multiples (`p-4`, `p-6`, `p-8`).
